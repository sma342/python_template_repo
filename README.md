# 🇬🇧 British Edgy App

Prosta aplikacja konsolowa (CLI) z dedykowanym modułem logicznym, która ocenia Twój poziom "edgy Brytyjczyka" na podstawie pogody, stanu zapasów herbaty oraz zawartości portfela. Projekt demonstracyjny zawierający testy jednostkowe, konfigurację jakości kodu oraz potok CI.

---
